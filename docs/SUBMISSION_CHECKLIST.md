## 代码与配置

- Vue 前端源码与 dist、FastAPI 后端、测试、业务规则和知识库齐全。
- 模型权重由 Git LFS 提供，首次克隆执行 `git lfs pull`。
- 环境模板 `.env.example`、Python 依赖清单、npm 依赖与锁文件齐全；首次安装包含 NumPy，命令见 README。
- 真实密钥通过服务端环境变量或不提交的 `.env` 配置，用户数据库与签名私钥不公开。
- 提交记录见仓库 Commits，保持实际变更可追溯。
