## 运行
1. 解压到普通目录，运行 start_server.bat。需要 Python，首次需要网络安装依赖；不是完全离线安装包。
2. 默认访问 http://127.0.0.1:8010 ，演示账号 wbtest / wbtest123。
3. 没有 Key 时可体验本地眼底筛查、离线症状与 Agent；化验单和多模态综合分析需要模型服务。
4. 在线使用：复制 .env.example 为 .env，填写自己的 ARK_API_KEY。文本和视觉默认分开配置，视觉可能按量计费。
5. 本机真实 Key 已恢复在项目 .env；公开提交包不包含该文件、JWT 签名密钥和真实运行数据库。
