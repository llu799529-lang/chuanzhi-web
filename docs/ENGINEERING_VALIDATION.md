## 本轮修复
- 账号切换清空历史、用量及待传科室，丢弃旧账号迟到响应。
- 化验缓存绑定所属账号；旧账号迟到上传不能写到新账号。
- 聊天识别的化验单在已挂载的化验页正确同步。
- 综合分析发送完整化验明细，缓存签名随报告变化。
- 检索扩展前过滤明确否定症状；保留转折和“无力”等肯定症状。
- 红旗自检核对及时就医措辞；不再只凭“医院/医生”一词通过。
- 图片单独使用已验证的 DeepSeek-V4.1-Flash 经济版；文本正式版及自动付费兜底关闭设置保留。
- 固定演示测试分析器，避免真实权重使测试走错分支；子进程输出显式 UTF-8。
- MCP 初始化日志转到 stderr，避免污染 JSON-RPC 通道。
- 窄屏补充页面导航并约束顶栏溢出，桌面卡片和配色沿用原样。
- 格式标签沿用原版展示，PDF/DICOM 的悬浮提示明确当前上传入口接受图片；排除内部评分计划和旧清单重复条目。

## 真实模型验证口径
报告：backend/evals/live_smoke_report.json。文本使用 deepseek-v4-flash-ga-260731；视觉使用 deepseek-v4-1-flash-economy-261017。
正式版曾把合成化验单误判为眼底，该失败记录保留在 previous_vision_checks。切换经济版后仅额外请求一次，正确识别 3 项指标，并核对血糖 8.5 与 HbA1c 8.2。
报告中的 6/6 是核查项数量，累计实际请求为 8；一次合成图片调用可支持图片输入和数值核对两项检查。
没有复跑完整临床图像评测，没有做真实用户试点，不把该合成测试当作医疗准确率。
