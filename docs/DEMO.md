# MedTriage 功能演示流程

**在线入口：[http://101.37.180.16](http://101.37.180.16)**。先登录或注册；需要本地体验时按根目录运行说明准备环境。

建议顺序为“使用指南 → 眼底筛查 → 化验单 → 症状与 Agent → 综合分析 → 就医导航”，覆盖从输入到就医信息的完整流程。

## 1. 使用指南与眼底上传

打开“使用指南”，展示上传步骤与拍摄要求，进入眼底页选择示例 A。等待页面处理状态与服务端报告完成，查看图像质量、五级概率、分级和就诊建议。
再选择示例 B，演示失焦图像的质量提示与重拍入口。两张示例均通过实际上传接口，不预填固定分级结果。

## 2. 专业阅片与双眼筛查

在报告中切换原图、增强图和绿色通道，调节 Grad-CAM 热力层强度，使用并排视图与同步放大。
双眼模式分别提交左右眼图片，并显示两眼结果及较重等级对应的就医参考。图像处理只影响浏览器显示，不改写分级或概率。
热力图用于展示模型关注区域，结合原图、质量提示与医生判断解读。

## 3. 化验单与数值核验

选择页面内置的合成化验单，展示视觉结构化结果：项目名称、数值、单位、参考范围、分类表和逐项解读。
查看数值核验标记：参考范围、单位或数量级需要核对时给出提示，原识别值保留。图片识别需要在线视觉模型配置。

## 4. 症状分诊与 Agent 工作台

示例输入：“头晕三天该看什么科？”观察工作台的工具调用、检索、报告、引用来源与就诊准备。按系统追问补充信息，展示多轮交互。
另用“胸口疼，出冷汗，放射到左肩”演示急症规则闸门：命中相应规则时直接给出急症指引，不等待云端生成。
演示以实际响应为准，不预设疑似方向百分比，也不把报告中的展示分值称为医学确诊概率。

## 5. 历史与综合分析

进入历史页查看当前账号的筛查记录，打开多模态综合分析，展示眼底、化验和症状信息的交叉解读。
切换账号时检查页面按新账号重新加载，说明个人记录与缓存的账号边界。

## 6. 就医导航与服务状态

从报告进入“附近医院”，展示科室条件、地图与医院结果。相关能力按部署环境中的高德配置启用。
查看服务状态，区分本地模型、在线文本/视觉、地图和离线规则能力。在线服务不可用时，页面显示相应提示或明确标注的降级结果。

## 演示素材与说明

眼底和合成化验单素材位于 `演示素材/`，页面也提供示例入口。图文步骤见根目录 `02_作品介绍与操作手册.pdf`。
本地上传眼底推理不消耗云端模型请求；化验识别、在线 Agent 与综合分析会按服务器配置调用服务。录制时复用既有记录可减少重复调用。
结果用于筛查与就医信息参考，不替代医生诊断；测试指标及其任务范围见 [EVAL.md](EVAL.md)。
