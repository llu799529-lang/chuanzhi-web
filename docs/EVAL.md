本文汇总仓库内已有实验报告；当前工程测试见 [ENGINEERING_VALIDATION.md](ENGINEERING_VALIDATION.md)。所有指标按对应样本、任务和实验范围解释。

## 眼底五级分类

模型为 EfficientNet-B3，推理输入 300px，使用水平翻转 TTA。既有 test 集包含 508 张图片。

| 指标 | 结果 |
|---|---:|
| 五级分类准确率 | 76.57% |
| Quadratic Weighted Kappa | 0.8958 |
| 跨两级及以上误分 | 21 / 508 |
| 其中低估两级及以上 | 13 / 508 |
| 1 级召回率 | 53.4% |
| 3 级召回率 | 57.7% |

以 DR≥2 为可转诊标准，在同一既有样本上统计：敏感度 94.2%（211/224）、特异度 90.5%（257/284）；校准误差 ECE 约 0.041。
二分类可转诊指标与五级分类准确率属于不同任务，不相互替代。

来源：`backend/evals/fundus_report.json`、`fundus_rows_test.json`，混淆矩阵与逐图结果随仓库保留。valid 集用于模型选择，test 集用于相应测试报告。
数据导出尺寸为 224×224，与训练图像的原始分辨率存在差异；这是公开数据上的回顾性结果，不等同于前瞻性临床验证。

```bash
cd backend
python evals/eval_fundus.py --split test
```

完整重跑需要报告对应的数据集目录与环境配置，具体参数见脚本帮助。

## 知识检索

默认检索包含关键词、bigram、双向同义词与否定处理。知识库 100 条，其中 94 条具有登记来源；条目与参考文献见 [KB_SOURCES.md](KB_SOURCES.md)。

| 查询集合 | 数量 | Top-1 | Top-3 | MRR@3 | 用途 |
|---|---:|---:|---:|---:|---|
| golden | 50 | 0.900 | 1.000 | 0.950 | 调优后的回归检查 |
| 历史查询 | 95 | 0.863 | 0.989 | 0.918 | 回归检查 |
| 作者自建留出查询 | 64 | 0.766 | 0.938 | 0.849 | 留出评估 |

10 条非医疗负例误召回为 0。前两组参与过调优；64 条留出查询仍由作者构建，区别于外部独立标注集。Top-k 命中衡量检索，不等同于医学回答正确率。

来源：`backend/evals/retrieval_compare.json`。BM25 重排与融合的对比结果同时保留，默认采用现有 baseline 配置。

```bash
cd backend
python evals/run_retrieval_compare.py
```
